## Decisions and limits

- The measured default for `keepalive.task` is off. Twenty-second WebSocket control pings kept the URL connection open without a task.
- The initial request after a machine restart cannot be assumed to load the page. Keep the documented reload caveat.
- Disable the X screen saver explicitly. Absence of a screensaver package does not disable Xvnc's built-in saver.
- An explicit `sprite-env services stop desktop-m0` left the service stopped/failed; URL requests returned 502 and did not restart it. This differs from process failure: sending KILL through `services signal` did trigger automatic restart. Do not use an explicit service stop as a simulated crash.
- The test client uses an org Bearer token from `SPRITES_TOKEN`. It never puts the token in the browser or result files. These tests cannot establish cookie-authenticated browser WebSocket behavior.
- The agent browser reached Fly's sign-in form without a Fly session. Josh separately completed the real browser flow and reported successful text and binary echoes at 22:46:31–32 UTC. Josh subsequently reported `SameSite=Lax` from browser inspection.

## Reproduce

Set URL policy before installing any HTTP service:

```sh
sprite api /v1/sprites/sprite-desktop-v1-probe -- -fSs -X PUT \
  -H 'Content-Type: application/json' \
  -d '{"url_settings":{"auth":"sprite","private_access":"admins"}}'
sprite api /v1/sprites/sprite-desktop-v1-probe -- -fSs
```

Build the disposable probe and upload it. A fresh service uses:

```sh
CGO_ENABLED=0 go -C probes build -o /tmp/sprite-desktop-m0 .
sprite exec -s sprite-desktop-v1-probe --no-port-forward \
  --file /tmp/sprite-desktop-m0:/home/sprite/desktop-m0 \
  -- chmod 755 /home/sprite/desktop-m0
sprite exec -s sprite-desktop-v1-probe --no-port-forward -- \
  sprite-env services create desktop-m0 --cmd /home/sprite/desktop-m0 \
  --args '-origin,https://sprite-desktop-v1-probe-6ra.sprites.app,-ping-interval,20s' \
  --http-port 8080 --no-stream
sprite api /v1/sprites/sprite-desktop-v1-probe/exec -- -fSs
pnpm exec tsx probes/check.ts --seconds 1800 --report /tmp/m0-soak.json
```

Do not leave exec or console sessions open during that command. Do not poll the URL, `/check`, or service state during the soak. The client sends only the initial echoes, automatic pong replies, and the post-idle echo.

For the task-held trial, start the probe with `-task-hold` appended to its arguments, then run `probes/check.ts --seconds 300 --require-task`. The task endpoint is `PUT http://sprite/v1/tasks/desktop-m0-hold` with `{"expire":"90s"}` over `/.sprite/api.sock`; DELETE releases it.

The SDK/restart check is deliberately hard-coded to the disposable Sprite:

```sh
pnpm exec tsx packages/sprite-provision/src/probe-platform.ts
```

For screen-state checks, first run the unchanged v0 provisioner against the disposable Sprite and install the test-only `libxss1` package. Upload and execute `probes/blanking.py` with `/usr/bin/python3`. It runs for fifteen minutes and terminates only its own `:2` Xvnc process.
